Security Policy

Thank you for taking the time to report a possible security issue in this repository.

Reporting
- Preferred: Use GitHub’s private Security Advisories for this repository: go to the repository > Security > Advisories > Create new draft advisory. This keeps details private while we investigate.
- Alternative: Open a private issue labelled "security" (set to private via the Security Advisories flow) or contact the repository owner via their GitHub profile.

What to include
- A short title and summary of the issue
- Steps to reproduce (minimal test case or PoC) and expected vs actual behaviour
- Affected versions/files and any log output or stack traces
- Any suggested mitigation or fix you think is appropriate

Handling & timelines
- Acknowledgement: within 5 business days
- Triage & initial response: within 10 business days
- Fix and coordinated disclosure: target within 90 days (may vary by severity)

Sensitive data
- Do NOT include secrets, credentials, or private data in reports. Use the private advisory form or encrypted attachments.
- If you must send sensitive details by email, encrypt them with our PGP key (add a PGP key here) or use the GitHub private advisory.

CVE requests
- If a CVE is required, request it during coordinated disclosure and we will help obtain one when the fix is ready.

Thank you
We appreciate responsible disclosure and will work to resolve verified vulnerabilities as quickly as practical.
